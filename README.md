# HomeBase Essentials website

This repository powers https://homebaseessentials.github.io/homebaseessentials/

## Files
- `index.html`: website content and structure
- `style.css`: navy/gold visual design
- `script.js`: language switch, products, cart, delivery and quote interactions
- `assets/`: original brand images

## Updating GitHub
Upload all files and the assets folder to the root of the existing `homebaseessentials/homebaseessentials` repository. Replace `index.html` and `README.md`; add `style.css`, `script.js`, and the assets files. Do not upload the ZIP directly.

## Before accepting orders
Products/prices are illustrative. The cart does not process payment or place orders. The quote form and order-copy feature do not transmit requests to the business. Delivery area, fees, and fulfillment must be confirmed.
